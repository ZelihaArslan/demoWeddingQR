# DemoWedding QR

Düğün ve özel etkinlikler için dijital QR kod tabanlı fotoğraf/anı paylaşım sistemi.

## Özellikler
* **Hızlı QR Erişimi:** Konukların uygulama indirmeden tek taramayla etkinlik sayfasına ulaşması.
* **Dijital Anı Defteri / Galeri:** Katılımcıların düğün sırasında çektikleri fotoğraf ve videoları doğrudan sisteme yükleyebilmesi.
